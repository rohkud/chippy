case class DebugModuleParams(baseAddress: BigInt = BigInt(0), nDMIAddrSize: Int = 7, nProgramBufferWords: Int = 16, nAbstractDataWords: Int = 4, nScratch: Int = 1, hasBusMaster: Boolean = false, clockGate: Boolean = true, maxSupportedSBAccess: Int = 32, supportQuickAccess: Boolean = false, supportHartArray: Boolean = true, nHaltGroups: Int = 1, nExtTriggers: Int = 0, hasHartResets: Boolean = false, hasImplicitEbreak: Boolean = false, hasAuthentication: Boolean = false, crossingHasSafeReset: Boolean = true) extends Product with Serializable

Parameters exposed to the top-level design, set based on external requirements, etc.

This object checks that the parameters conform to the full specification. The implementation which receives this object can perform more checks on what that implementation actually supports.

baseAddress

Base offest for debugEntry and debugException

nDMIAddrSize

Size of the Debug Bus Address

nAbstractDataWords

Number of 32-bit words for Abstract Commands

hasBusMaster

Whether or not a bus master should be included

clockGate

Whether or not to use dmactive as the clockgate for debug module

maxSupportedSBAccess

Maximum transaction size supported by System Bus Access logic.

supportQuickAccess

Whether or not to support the quick access command.

supportHartArray

Whether or not to implement the hart array register (if >1 hart).

nHaltGroups

Number of halt groups

nExtTriggers

Number of external triggers

hasHartResets

Feature to reset all the currently selected harts

hasImplicitEbreak

There is an additional RO program buffer word containing an ebreak

crossingHasSafeReset

Include "safe" logic in Async Crossings so that only one side needs to be reset.
