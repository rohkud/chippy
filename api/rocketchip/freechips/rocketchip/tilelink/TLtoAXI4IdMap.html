TLtoAXI4IdMap

class TLtoAXI4IdMap extends IdMap[TLToAXI4IdMapEntry]

TLtoAXI4IdMap serves as a record for the translation performed between id spaces.

Its member [axi4Masters] is used as the new AXI4MasterParameters in diplomacy. Its member [mapping] is used as the template for the circuit generated in TLToAXI4Node.module.
