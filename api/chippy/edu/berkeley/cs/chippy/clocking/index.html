    This node combines sets of clock groups according to functions provided in the ClockGroupCombinerKey The ClockGroupCombinersKey contains a list of tuples of:

    • The name of the combined group
    • A function on the ClockSinkParameters, returning True if the associated clock group should be grouped by this node This node will fail if
    • Multiple grouping functions match a single clock group
    • A grouping function matches zero clock groups
    • A grouping function matches clock groups with different requested frequncies
