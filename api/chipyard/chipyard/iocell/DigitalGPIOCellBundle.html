DigitalGPIOCellBundle

class DigitalGPIOCellBundle extends Bundle

The base IO bundle for a signal with runtime-controllable direction pad: off-chip (external) connection i: input to chip logic (output from IO cell) ie: enable signal for i o: output from chip logic (input to IO cell) oe: enable signal for o
